Las variables de entorno se especifican dentro de un archivo .env que se encuentra en el directorio del programa (este directorio)
Ahi se declara la variable asi:
NOMBRE=VALOR
Valor no tiene que llevar "" ni '', entiendo es ideal que no hayan espacios en el igual.
Ademas de eso hay que instalar lo que se encuentra en el requirements.txt
El comando es: pip install -r requirements.txt
